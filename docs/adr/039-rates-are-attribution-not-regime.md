# ADR-039: 金利変数はレジーム判定に組み込まず、帰属と異常検知に限定して使う

Status: accepted
Date: 2026-08-24

## Context

2026-08-17〜19 の3営業日で SOXL は $151.53 → $120.74 まで下げた。当時の報道（The Motley Fool「Chip Stocks Didn't Fall on Chip News This Week. They Fell on a 19-Year High in the 30-Year Treasury Yield.」2026-08-21）と、それを採用した本プロジェクトの記録は、この下落を米30年債利回りの上昇（8/17 に 5.311% = 2007年6月以来、8/18 日中 5.33% 超）に帰属していた。

この期間 `regime_assessments` は一貫して `risk_on` を出し続けていた。既存6指標（VIX / VIX3M / HY_SPREAD / YIELD_CURVE / BRENT / USD_INDEX）のいずれも長期金利の水準を見ていないためである。

issue#26 はこれを「長期金利を収集していないので構造的に検知できない」と整理し、次の2段階を提案した。

1. FRED の DGS30 を収集系列に追加する
2. レジーム判定に長期金利の水準と変化の軸を足す

段階1は実施した（commit `aaeeff7`）。段階2を実装するにあたり、閾値をどこに置くかを決めるため実測を行ったところ、**前提そのものが成り立たないことが判明した**。本 ADR はその測定結果に基づく決定を記録する。

### 測定の内容

対象は SOXX（半導体ETF）と SPY の日次リターン、および FRED / yfinance から取得した金利関連変数。期間は 2021-08〜2026-08。

**(a) 同日の連動**（各変数の日次変化 vs SOXX 当日リターン、n=1289）

| 変数 | r | t | 超過リターン(SOXX-SPY) の t |
|---|---|---|---|
| 30年 名目金利 | -0.035 | **-1.24** | -0.48 |
| 30年 実質金利 (DFII30) | -0.093 | -3.36 | -1.62 |
| 30年 期待インフレ (DGS30 - DFII30) | +0.090 | **+3.24** | +1.81 |
| MOVE（債券ボラティリティ） | -0.184 | **-6.72** | **-3.31** |
| 2年債 / 20年債 / ターム・プレミアム | — | いずれも \|t\| < 1.3 | — |

名目金利が有意でない理由は重回帰で確定した（n=1289）。

```
SOXX当日リターン(%) = -0.573 × 実質金利(+10bp)      t = -3.30
                      +0.928 × 期待インフレ(+10bp)   t = +3.18
```

両者は**逆符号**で、日次変化の相関は -0.022 とほぼ独立である。名目金利は両者の和なので、効果が打ち消し合って情報が消える。

MOVE は金利テーマの全変数のうち唯一、半導体固有ぶん（SOXX - SPY）にも5年通して有意だった。

**(b) 翌日の予測**（当日の状態 → 翌日リターン）

`y30` / `real30` / `move` の3変数を、次の3手法それぞれで5分位に分類した。

- 生の水準
- 直近252営業日内の相対位置（トレンド除去）
- 5営業日変化

**9通りすべてで、無条件平均から2標準誤差離れる帯が一つも無かった。**

生の水準では「金利が高い帯のほうが翌日リターンが良い」という逆の結果が出る（30年実質金利の上位10%帯で翌日 +0.455、勝率 60.5%、無条件 +0.083 / 53.6%）。これは 2021-2026 にかけて金利と半導体が同時に上昇したトレンドの交絡で、トレンド除去すると消える。

**(c) 値幅（sizing への応用可能性）**

方向が当たらなくても値幅が当たれば ADR-028 の sizing（投入割合 = risk% ÷ stop距離%）に直結するため、別途検証した。実質金利の上位10%帯（閾値 2.65%）で翌日の |SOXX| が 2.625% 対 無条件 1.808%、差 +0.817 ±0.191（4.3SE）と一度は出た。

しかし該当131日のうち106日が2026年に集中していた。年除外テストの結果は次の通り。

```
2025年を除外 (≒2026年のみ) → 差 +1.209 ±0.231  t = +5.24
2026年を除外               → 差 -0.517 ±0.206  t = -2.51   ← 符号が逆転
```

2026年を外すと逆に値幅が小さくなる。(b) と同じトレンド交絡であり、棄却した。

なお翌日の |SOXX| を最もよく説明するのは SOXX 自身の直近5日ボラ（r=+0.109, t=+3.92）で、金利系の全変数（t≈+1.06〜+1.35）を上回る。MOVE を重回帰で足しても上乗せがない（MOVE水準 t=+1.03、SOXX直近5日ボラ t=+3.85、R²=0.0127, n=1282）。

**(d) 元の episode の再検証**

issue#26 の出発点だった 2026-08-17〜19 を、実際の金利データと突き合わせた。

| 日付 | 30年名目 | 30年実質 | MOVE | SOXX | SPY |
|---|---|---|---|---|---|
| 8/17 | 5.31% (**+6bp**、19年ぶり高値) | +6bp | 75.63 (**+6.05**) | **+1.58%** | -0.47% |
| 8/18 | 5.28% (**-3bp**) | -3bp | 74.98 (-0.65) | **-4.96%** | -0.68% |
| 8/19 | 5.19% (**-9bp**) | -9bp | 71.26 (-3.72) | **-2.21%** | +0.21% |

**金利がピークをつけた 8/17、SOXX は市場全体が下げる中で +1.58% と逆行高している。暴落した2日間はいずれも金利・実質金利・MOVE がそろって下げている。**

すなわち、金利をレジーム判定に組み込んでいても、issue#26 の動機となったこの暴落は検知できなかった。

留保: これは日次終値であり、8/18 に日中 5.33% まで上げて 5.285% で引けた事実は終値では見えない。ただし 8/19 は終日 9bp 低下しており、日中値でも救えない。

## Options

| 選択肢 | 長所 | 短所 | 採否 |
|--------|------|------|------|
| A. 名目長期金利(US30Y)の水準を6指標に追加する | issue#26 の当初案。実装が最も単純 | 名目は5年 n=1289 で t=-1.24 と有意でない。水準の閾値は9通りの検定で一つも有意な帯が無い。**データが支持しない関係をコードに埋め込むことになる** | 不採用 |
| B. 実質金利(DFII30)の水準を6指標に追加する | 同日連動は有意(t=-3.36)。名目より筋が良い | 翌日予測は名目と同様に有意でない。生の水準では符号が逆に出て、トレンド除去で消える | 不採用 |
| C. MOVE の水準を6指標に追加する | 金利変数で唯一、半導体固有ぶんに有意(t=-3.31)。VIX と同じ「ボラティリティ指標」で既存体系に馴染む | 同日連動であって予測ではない。水準分類では有意な帯が無く、値幅予測でも SOXX 自身のボラに対する上乗せがゼロ(t=+1.03) | 不採用 |
| D. 金利変数をレジーム判定に組み込まず、帰属と異常検知に限定する | 測定結果と整合する。誤った関係を実装しない。段階1で集めたデータは無駄にならない | 「金利を見ている」という安心感は得られない。帰属は自動判定でなく都度の照会になる | **採用** |
| E. 金利変数を収集ごと取りやめる | 最も単純 | 同日連動(帰属)は実際に有意であり、捨てると 8/17-19 型の誤帰属を検証する手段を失う | 不採用 |

## Decision

> **金利変数（US30Y / REAL10Y / REAL30Y / BREAKEVEN10Y / MOVE）を `regime.py` のレジーム判定に組み込まない。**
>
> `regime_assessments` のスキーマも変更しない（ADR-009 の入力値スナップショットに金利列を追加しない）。レジーム判定の入力は既存6指標のままとする。
>
> 収集した金利変数は次の2用途に限定して使う。
>
> 1. **帰属**: 半導体が下げた日の原因を切り分ける。名目金利ではなく、実質金利・期待インフレ・MOVE の3つに分けて符号を確認する。`/scan-market` の手順書に必須手順として組み込み済み。
> 2. **異常検知**: 各系列の最新の日次変化が、その系列自身の直近252営業日の変化に対して 2σ を超えたらサマリーに表示する（`update_data.unusual_move_z`）。**方向のシグナルではなく、原因を確認しに行く合図**である。
>
> `impact_reasoning` や会話で「金利が高いので今後も下がる」と書かない。金利を Channel 3 の driver として書く時は、**当日の符号を必ず確認する**。符号が逆なら金利を driver として書かない。

## Rationale

**1. データが支持しない関係を実装しないこと自体が設計判断である。**

レジーム判定は水準で分類する構造（`VIX < 16 → low` 等）を持つ。金利変数を追加するには閾値を決める必要があるが、置ける場所が無い。9通りの検定で有意な帯が一つも無く、生の水準で出る「高金利のほうが翌日リターンが良い」はトレンド交絡で消える。ここで恣意的に閾値を置けば、`regime_assessments` は「根拠のある判定」の外観を持ちながら中身がノイズになる。これは判定が無いことより悪い。

**2. 同日連動と翌日予測を区別する。**

金利変数は同日連動では明確に有意である（実質 t=-3.30、期待インフレ t=+3.18、MOVE t=-6.72）。この事実は「下げた原因を説明する」には十分だが、「明日どうなるか」には何も言わない。両者を混同すると、説明力を予測力と誤認して判断に使ってしまう。ADR-034 が inclusion に realized impact を使うことを禁じているのと同じ構造の危険である。

**3. 段階1を無駄にしない。**

issue#26 の段階1（収集）は結果的に正しかった。ただし当初案の「DGS30 を1本足す」では不十分で、実質金利と期待インフレへの分解が必要だった。名目1本では2つの逆符号の効果が打ち消し合い、帰属にも使えない。

**4. 元の動機が成立しない以上、当初案を実装する理由が無い。**

issue#26 は「集めていれば検知できたはず」という前提で立った。(d) の再検証でその前提が崩れた。前提が崩れた提案を、issue が存在するという理由だけで実装しない。

**5. 用途の段を明示する（K-075）。**

指標には ①方向を当てる ②値幅を当てる ③帰属する ④異常に気づく の4段の用途がある。①②の検定で落ちたことは③④で使えないことを意味しない。逆に③④で使えることを①②の言葉（「効く」「使える」）で語ってもいけない。本 ADR は金利変数を①②から外し③④に置く決定である。

## Consequences

**反映先**

- `src/regime.py`: 変更なし（これが決定内容）
- `src/providers.py` / `src/fred_client.py`: US30Y / REAL10Y / REAL30Y / BREAKEVEN10Y / MOVE の収集経路（実装済み）。用途の限定をコメントに記載
- `update_data.py`: サマリーを2ブロックに分割し「金利分解: 帰属専用・レジーム判定には使わない」と見出しで明示。`unusual_move_z` による異常フラグ（実装済み）
- `.claude/skills/scan-market/SKILL.md`: 「帰属バイアスの補正」節に金利の切り分け手順を必須として追加（実装済み）
- `docs/event-channels.md`: チャネル3 の記述を拡張
- knowledge: K-073（複数ソースの相互一致は正確さの証明にならない）、K-074（金利は帰属に使えるが予測に使えない）、K-075（指標の用途は4段）

**トレードオフ**

- レジーム判定は今後も長期金利を見ない。金利主導の局面が実際に存在した場合、判定は引き続き取り逃す。これは「取り逃す」ことを承知の上での決定であり、代わりに帰属の段で人間と Claude が確認する
- 帰属は自動でなく都度の照会になる。`/scan-market` の手順書に組み込んだが、手順を踏まなければ機能しない
- MOVE は K-073 の基準では未検証。一次公表元が ICE BofA で無償の照合先が無く、yfinance の値が公表値と一致するかを確認できていない。`^TYX` では財務省公表値に対し最大 0.0570 のズレがあった前例があるため、MOVE も同種のズレを持つ可能性を排除できない

**将来の見直しトリガー**

本 ADR は「現時点のデータでは支持されない」という判断であり、恒久的な禁止ではない。次のいずれかが起きたら再検討する（その場合は本 ADR を supersede する新 ADR を起こす）。

1. **サンプルが増えて結論が変わった時**: 現在の測定は 2021-08〜2026-08 の n≈1289。金利が下降するレジームを含む期間が加われば、トレンド交絡が薄まって水準の効果が見える可能性がある。目安として2年後（n≈1800）に再測定する
2. **日中データが入った時**: 現在の測定はすべて日次終値。8/18 の日中 5.33% のような動きは終値では見えない。日中の金利系列を収集する経路ができたら (d) の再検証をやり直す。ただし 8/19 は終日低下しており、日中値でも救えない点は変わらない
3. **異常検知フラグが実際に有用だった事例が蓄積した時**: `unusual_move_z` のフラグが立った日を `/review-events` で追跡し、「見に行って実際に何かが見つかった」割合が測れるようになったら、段4 の価値を定量化して段1・2 への昇格を検討する
4. **MOVE の一次公表元との照合手段ができた時**: ズレが無いことを確認できれば、MOVE 単独での再検討の価値がある（金利変数で唯一、半導体固有ぶんに有意だったため）
