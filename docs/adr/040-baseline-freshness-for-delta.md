# ADR-040: 乖離%の基準足も鮮度検査する（stale なら乖離%を出さない）

Status: accepted
Date: 2026-08-31

Extends: ADR-031（延長時間リアルタイム価格の取得）。ADR-031 の決定は覆さない。

## Context

ADR-031 は「プレ/アフターに stale な parquet 終値を現値扱いしない」を決め、`src/realtime.py` が
yfinance prepost から実勢を取る形にした。しかし乖離% (`delta_pct`) は **現値と基準終値の2値の関係**
であり、ADR-031 が差し替えたのは現値の側だけだった。基準側 (`regular_close`) は

```python
regular_close = float(daily.iloc[-1]["Close"])   # 鮮度検査なし
```

と parquet 日足の最終行を無条件に採用しており、parquet が stale なら基準も stale になる。
`summary()` も基準日を出さないため、読み手が「いつの終値と比べた数字か」を検算できなかった。

### 実インシデント（2026-08-31 18:50 JST）

parquet の最新日足が 2026-08-26 だった状態で SOXL の現値を取得した。

| | 値 | |
|---|---|---|
| 現値（yfinance prepost, 05:50 ET） | $112.36 | 正しい |
| 基準として使われた終値 | $116.60 | **8/26 の終値**（2営業日 stale） |
| 表示された乖離 | **-3.64%** | 誤り |
| 正しい基準（8/28 終値） | $111.34 | |
| 正しい乖離 | **+0.92%** | **符号が逆** |

実害は数値のずれではなく**方向を逆に読ませたこと**。「$112 を割ったあと $116.60 まで戻した」と
報告したが、実際は 8/28 に高値 $121.20 から $110.21 まで売られた大陰線で、無効化ラインは
割れたままだった。保護逆指値なしの SOXL 25株について、無効化ライン判定を誤らせた。

## Options

| 選択肢 | 長所 | 短所 | 採否 |
|--------|------|------|------|
| A. 基準日を summary に出すだけ | 最小変更 | 誤った乖離%自体は出続ける。読み手の注意力に依存し、忙しい時に素通りする | 不採用（単独では） |
| B. 基準が stale なら例外で止める | 誤読は完全に防げる | 現値そのものは正しく取れているのに取得ごと失敗する。データ更新できない時に現値が一切見られない | 不採用 |
| C. stale なら `delta_pct` を None にし、基準日と stale 日数を必ず出す | 誤読の源（乖離%）だけを消し、正しい現値は返す。基準日を常に出すので検算可能 | `delta_pct` が Optional になり呼び出し側の分岐が要る | **採用** |
| D. 週末のみ考慮する素朴な営業日計算 | 実装が短い | 祝日翌日に誤検知し、その警告はデータを更新しても消えない（存在しない日の終値を待つ）。消えない警告は無視する習慣を作り、検知機構が自壊する | 不採用 |

## Decision

> 1. `get_realtime_quote()` は `regular_close_date`（基準終値の日付）を**必須引数**として受け取る。
>    省略可能にすると呼び出し側が鮮度を黙って落とせてしまい、同じ事故が再発するため。
> 2. 基準日が「その時点で確定している直近レギュラー終値の日付」より古い場合、
>    **`delta_pct` は `None`** とする（誤読の源を出さない）。現値・session・is_thin は通常どおり返す。
> 3. `summary()` は stale の有無にかかわらず**基準日を常に表示**する。stale 時は乖離%の代わりに
>    「基準の MM-DD 終値 $X が N営業日古い→update_data.py」と復旧手段まで出す。
> 4. 営業日の判定は `src/market_calendar.py`（NYSE 祝日を含む）に置く。週末のみの素朴な計算は
>    祝日翌日に消えない誤警告を出すため使わない。
> 5. `quote_to_dict()` / `position_pnl.py` は `regular_close_date` と `baseline_stale_days` を
>    JSON に必ず含める。乖離%だけを読める状態を作らない。

## Rationale

- 乖離%は2値の関係なので、片方だけ新しくしても意味は保証されない。ADR-031 の規律
  （stale を黙って使わない）を基準側にも適用しただけで、ADR-031 の結論は変えていない。
- 選択肢 D を退けた理由が本 ADR の要点。**消せない警告は警告として機能しない**。
  2026-09-07 はレイバーデーで、翌 9/8（カナダ報復関税の発効日）のプレでは最新データが
  9/4 の終値であることが正しい状態になる。週末のみの計算だと「1営業日古い」と誤検知し、
  `update_data.py` を何度実行しても消えない。この種の警告は読み手を鈍らせ、元の事故を
  再発させる。
- カレンダーは外部依存を増やさず自前で持つ（`pandas_market_calendars` / `exchange_calendars`
  は未導入）。NYSE の規則は決定的に計算できる（固定日の土日振替、第N曜日、復活祭は
  Meeus/Jones/Butcher）。規則で導けない臨時休場（国葬・災害）は既知ぶんを列挙する。
- **検証**: SPY 日足 parquet の実バー 1305本（2021-06-18〜2026-08-28）と突合し、
  「営業日と判定したがバー無し」「休場と判定したがバー有り」ともに **0件**。
  初回は 2025-01-09（カーター元大統領の国葬）だけが乖離し、これを臨時休場として登録した。

## Consequences

- 反映先: `src/market_calendar.py`（新規）、`src/realtime.py`、`src/live_reads.py`、
  `scripts/position_pnl.py`、`scripts/watch_position.py`、
  `tests/test_market_calendar.py`（新規）、`tests/test_realtime.py`、`tests/test_live_reads.py`
- **`RealtimeQuote.delta_pct` が `Optional[float]` になった**。値を書式化する呼び出し側は
  None 分岐が必要（`watch_position.py` が該当し対応済み）。
- **将来の臨時休場は誤検知する**。国葬・災害等で NYSE が予定外に休場した翌営業日は
  「1営業日古い」と出る。その時は `_AD_HOC_CLOSURES` に日付を追加する
  （SPY 日足 parquet と突き合わせれば検出できる）。半日立会いは終値が存在するので影響なし。
- 見直しトリガー: `_AD_HOC_CLOSURES` の追加が年1回を超えて負担になる、または
  取引所カレンダーのライブラリを導入する判断をした時。
