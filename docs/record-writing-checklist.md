# 記録の自己完結チェックリスト

導入根拠: GDR-004
Created: 2026-07-01

永続化するあらゆる記録は、それを書いた会話を見ていない読者が単体で読めること。
判定 = 記録内のすべての語の参照先が、記録内（またはそれが含むリンク / ID）で解決する。

- **対象**: トラッカー issue / コメント・git commit・ADR / GDR・knowledge・doc・コード注釈
- **対象外**: 揮発的な会話・CLAUDE.md スタンス節（ここでは指示詞が正しく効率的）

理論的背景は GDR-004 を参照（Quine「永遠文」／ Kaplan「純粋指示詞」ほか）。

## 禁止（参照先が会話にしかない指示詞）

以下は「書いてはいけない語」の例示（列挙自体は言及であって使用ではない）。

- [ ] 会話依存の指示詞を書いていないか: 「次回」「さっき」「積み残し」「前ターンで」「as discussed」
- [ ] 時間の指示詞を書いていないか: 「最近」「現在」「今の sprint」「今日の」
      — 絶対日付でアンカーされない限り禁止（Kaplan: 時間の顔をした純粋指示詞）

## 許可（参照先が記録内で解決する）

- [ ] 絶対日付か: 2026-07-01（「今日」ではなく）
- [ ] ID か: ADR-025 / K-041 / Issue#12
- [ ] file path・リンクか
- [ ] 明示のトリガー / 完了条件か

## 過去状態の書き方

- [ ] 「X を Y に変えた」は、参照先が名前で固定されている時のみ可
      （例: 「GDR-004 が GDR-002 を supersede」のように ID / リンクでアンカーする。
      「以前の決定を撤回」のような無アンカーの過去参照は禁止）

## 執筆前テスト（Pinker「知の呪い」への対処）

- [ ] この記録を書いた会話を見ていない同僚が、すべての参照先と完了条件を自力で解決できるか？
