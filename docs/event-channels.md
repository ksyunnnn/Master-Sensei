# チャネル台帳（event-channels）

**役割**: 対象シンボル（SOXL 等のレバレッジ半導体 ETF）を実際に動かす**因果チャネル（経路）**の事前登録リスト。events テーブルへの登録判定（ADR-034）の Rule層で、この台帳との照合（lookup）に使う。

**性質**: これは *living データ*（時間とともに育つ）。判断ロジックの決定そのものは ADR-034（immutable）にあり、この台帳はその決定に基づく**運用データ**として git で版管理する。変更＝チャネルの昇格/降格は、`review-events` の事後採点に基づく**明示的な編集**として行う（git diff がドリフトの監査証跡になる）。

**使い方（ADR-034 の2層プロトコル要約）**:
1. **Rule層**: イベントが下記チャネルのいずれかへのショックか？ → Yes なら登録。どれにも当たらず新規経路の兆候もなければ登録しない。
2. **Standard層**: 綺麗に当たらない曖昧ケースは固定サブ質問（ADR-034）で構造化判断。迷えば `impact=neutral`・低 relevance で捕捉（可逆）。新規経路の疑いは「候補チャネル」節に追記。
3. inclusion に「実際に動いたか」を使わない（look-ahead 禁止）。realized impact は `review-events` の出口採点でのみ用い、この台帳の昇格/降格に反映する。

**relevance の付け方**: direct（チャネルが半導体を直接駆動）/ indirect（マクロ経由）/ background（遠因）。

## 確定チャネル

### 1. AI compute 需要
- **説明**: hyperscaler（大手クラウド）の設備投資・受注・データセンタ計画など、AI インフラ投資の *総量* シグナル。
- **既定 relevance**: direct
- **例**: Meta が余剰 AI compute を cloud 再販との報道（2026-07-01）／Broadcom の AI 半導体売上ガイド・見通し据え置き（2026-06-04）。
- **境界注記**: 個別企業の一般業績ではなく、AI インフラ投資の総需要の増減シグナルに限る。capex 拡大＝positive、天井/減速シグナル＝negative 方向。

### 2. メモリ / HBM 需給
- **説明**: DRAM・HBM の増産/減産、価格、在庫、歩留まり。
- **既定 relevance**: direct
- **例**: SK Hynix の HBM 増産ペース鈍化報道（2026-07-02）／Micron 決算（2026-06-24）。
- **境界注記**: メモリ固有の需給。メモリ主導の局面では Nvidia/Broadcom 等ロジックより先行/深く動くことがある。

### 3. 金利・割引率（Fed 政策 + 長期金利）
- **説明**: long-duration 成長株（AI/半導体）の割引率に効く経路。2つの源がある。
  - **政策金利側**: FOMC 声明/議事録、要人発言、インフレ・雇用統計の政策含意。
  - **長期金利側**: 財政赤字・国債需給・ターム・プレミアム主導の長期ゾーンの動き。政策金利が据置でも独立に動く（2026年は FEDFUNDS 3.63% 据置のまま30年債が 4.63% → 5.31%）。財務省のバイバック増減など需給操作もここに含む。
- **既定 relevance**: indirect
- **例**: 新 Fed 議長の追加利上げ示唆／NFP・PCE・CPI の政策含意／米財務省の長期債バイバック倍増（2026-08-19）。
- **境界注記**: マクロ経由の indirect が多い。統計の *結果* そのものより、政策パスへの含意で判定する。
- **金利を driver として書く前に、名目でなく分解を見る（ADR-039 / K-074、必須）**: 名目長期金利は SOXX に対し5年 n=1289 で r=-0.035 / t=-1.24 と**有意でない**。実質金利（-0.573%/10bp, t=-3.30）と期待インフレ（+0.928%/10bp, t=+3.18）が**逆符号で打ち消し合う**ため。`data/parquet/macro/` の `REAL30Y`（上昇=逆風）・`BREAKEVEN10Y` および `US30Y - REAL30Y`（上昇=順風）・`MOVE`（上昇=逆風、半導体固有ぶんに効く唯一の金利変数 t=-3.31）を引き、**当日の符号が逆なら金利を driver として書かない**。
- **予測には使えない**: 上記はいずれも同日連動であり、水準・トレンド除去後の相対位置・5日変化のいずれでも翌日を分けない。`impact_reasoning` に「金利が高いので今後も下がる」と書かない。レジーム判定にも組み込まない（ADR-039）。
- **反例（このチャネルを過剰適用した実例）**: 2026-08-17〜19 の SOXL 下落を当初このチャネルに帰属したが、8/17 は30年金利が +6bp の 5.31%（19年ぶり高値）に達した日に SOXX が +1.58%（SPY -0.47% に対し逆行高）、暴落した 8/18 は金利 -3bp、8/19 は -9bp だった。報道（Motley Fool 2026-08-21）をそのまま採用し値と突き合わせなかった誤り（K-073 と同型）。

### 4. 通商・輸出規制
- **説明**: Section 232、対中半導体輸出規制、関税。半導体サプライチェーンのコスト・アクセスに触れる政策。
- **既定 relevance**: direct〜indirect
- **例**: Section 232 半導体 proclamation／対中チップ関税の発効・延期。
- **境界注記**: 半導体・製造装置・派生製品に触れるものに限る。一般関税ニュースはスコープ外。

### 5. ポジショニング・流動性
- **説明**: crowded trade の巻き戻し、資金フロー、セクターローテーション（Great Rotation 等）。外部ニュースでなく市場内部の需給要因。
- **既定 relevance**: direct
- **例**: H1 で +80% 上げた半導体からの利益確定/巻き戻し（2026-07-01〜02）。
- **境界注記**: 外部触媒との区別が重要。「無触媒の positioning 巻き戻し」と「触媒 driven の de-rating」は反発挙動が異なる（K-046 の境界条件）。触媒が実在する場合はそのチャネル（1〜4等）にも同時に該当しうる。

### 6. システミック risk-off
- **説明**: 地政学ショック・信用イベント・VIX スパイク等で、半導体が高 beta ゆえに市場全体と共に下げる局面。
- **既定 relevance**: indirect〜background
- **例**: 地政学エスカレーション時の広範な risk-off。
- **境界注記**: 半導体固有ではなく、市場全体の risk-off が beta 経由で波及するもの。半導体固有ストレス（例: VIX 低位 / VXN 高止まりのデカップリング）とは区別する。

## 候補チャネル（未確定・観察中）

確定チャネルに綺麗に当たらないが伝播経路が疑われるイベントを、ここに記録して観察する。`review-events` の採点で繰り返し有意な price impact が確認されたら確定チャネルへ**昇格**する。

### 候補1. AI 融資・信用構造
- **説明**: 循環ファイナンス（ベンダーが顧客に出資 → その資金で顧客が自社製品を購入）、neocloud（CoreWeave 等）の債務・資金ギャップ、簿外 SPV、AI 発行体のクレジット（CDS・スプレッド）。資金調達コスト上昇・信用ストレス → 強制 capex 削減 → 半導体需要エアポケット、という伝播経路。
- **想定 relevance**: indirect
- **例**: Nvidia–CoreWeave–Nebius 循環（各 $2B 出資＋未利用 capacity 買取保証 $6.3B）／Oracle 5年 CDS が 2008 危機ピーク超え（2026-07）／BIS が循環ファイナンス崩壊を金融安定トップ3リスクに名指し。
- **確定6チャネルとの区別**: Channel 5（ポジショニング＝市場内部フロー）でも Channel 3（マクロ政策金利）でもなく、**企業の資本構造の脆弱性が資金コスト経由で需要持続性を脅かす**別経路。需要の *量* でなく *質/資金の持続性* を問う点で Channel 1 とも異なる。
- **昇格条件**: `review-events` の事後採点で、循環/信用イベント（neocloud 資金調達難・AI 発行体 CDS 拡大等）が繰り返し半導体に有意な price impact を与えたと確認された時に確定チャネルへ昇格する。
- **観察中の下位パターン: 購入連動ワラント（循環の逆向き）**。ベンダーが顧客に出資する Nvidia–CoreWeave 型に対し、**顧客が自らの購入額に連動してベンダーの株式を取得する**向きの構造がある。実例: Marvell が Google に最大 58,970,000 株・行使価格 $206.58（全部行使で $12.18B 相当）のワラントを付与（ワラント発行日 2026-08-18、商業契約は 2026-07-29 締結、行使期限 2033年8月）。初年度に自動確定するのは約140万株のみで、残る約5,760万株は Google の購入額 $500M ごとに約24万株が確定する。全マイルストーン達成時の売上見出し数字は FY2033 までで約 $120B。これは受注残ではなく条件付きの上限値であり、実質は株式形態の購入インセンティブ（リベート）で、売上が伸びるほど希薄化が進むため**収益の質を割り引いて読む必要がある**。need（数量）の証拠にはなるが return（収益性）の保証ではない（K-054）。
- **関連 knowledge**: K-054（need≠return≠price の3層分離）。
